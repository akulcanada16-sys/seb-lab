RESEARCH CONTRACT

Same engine. Inspectable assumptions.

This terminal runs the existing SEB strategy, feature, level, and historical-execution code inside your browser. The downloadable Python application runs that same research code.

  1. Validate the data. Timezone-aware, finalized one-minute prices. Invalid rows and duplicate or out-of-order timestamps are rejected.
  2. Evaluate chronologically. Strategies see only the market information available at each decision point.
  3. Model execution. Eligible decisions can enter on a subsequent bar. Stops, targets, gaps, and costs determine each completed trade.
  4. Make it reproducible. Export data, settings, engine identity, trades, and results together.

Bring your own data

Import CSV with these column headers:

timestamp,open,high,low,close,volume
2026-07-06T13:31:00Z,20000,20002,19999,20001,120

Timestamps identify bar close and must include a timezone. Prices must align to the 0.25-point MNQ tick. One-minute data only, up to 20,000 bars.

Your file stays in browser memory. Closing or refreshing the page discards it; export the experiment to keep it.

Interpret the results

The synthetic sample checks software behavior. It is not historical market evidence. Results on imported data are still subject to execution assumptions and data quality.

This terminal does not claim brokerage fills, future returns, funded-account qualification, or a strategy proven profitable.
